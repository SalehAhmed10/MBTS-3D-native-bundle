<objective>
Remove react-native-filament and all its dead artifacts from the project to eliminate the 107MB .so library layer that is causing the APK to be 147MB — 47MB over the 100MB budget.

Purpose: APK size must be under 100MB. The filament native libraries are the only blocker. Dead component files and Filament GLBs are cleaned up in the same pass.
Output: A buildable project with no Filament references, and an APK under ~95MB.
</objective>

<task id="2" name="Delete dead Filament source files and GLBs, clean metro.config.js">
  <read_first>
  - metro.config.js (read before editing — need exact current blockList content)
  </read_first>
  <action>
  1. Delete the three dead component files:
       - src/components/filament-preview.tsx
       - src/components/filament-preview.web.tsx  (paired web stub, also dead)
       - src/components/native-avatar-speech.tsx

  2. Delete the Filament GLBs that Metro was blocking:
       - assets/models/camilia.glb  (23MB)
       - assets/models/prithi.glb   (8.6MB)

  3. After both GLBs are deleted, remove the assets/models/ directory if it is now empty.

  4. Edit metro.config.js to remove the blockList entry. The current file is:

     ```js
     const { getDefaultConfig } = require("expo/metro-config");
     const config = getDefaultConfig(__dirname);
     config.resolver.assetExts.push("glb");
     const existingBlockList = config.resolver.blockList ? [].concat(config.resolver.blockList) : [];
     config.resolver.blockList = [...existingBlockList, /assets[/\\]models[/\\].*/];
     module.exports = config;
     ```

     Replace with:

     ```js
     const { getDefaultConfig } = require("expo/metro-config");
     const config = getDefaultConfig(__dirname);
     config.resolver.assetExts.push("glb");
     module.exports = config;
     ```

     Rationale: assets/models/ no longer exists, so the blockList rule is dead. The assetExts.push("glb") stays because android-local-assets GLBs may still be referenced via Metro in future tasks.

<task id="3" name="Verify clean Android build">

  - No additional files to read. Run the build and inspect output.
  </read_first>
  <action>
  1. Run a full Android build from a clean state:

     This triggers expo run:android which invokes Gradle. Expo's autolinking reads node_modules at build time and will exclude react-native-filament since it is uninstalled.

  2. If the build fails with a "filament" or "worklets" missing class error:
     - Check android/app/build.gradle for any hardcoded reference to react-native-filament (should not exist since autolinking managed it, but check).

  3. After a successful build, locate the generated APK. For a debug build it will be at:
       android/app/build/outputs/apk/debug/app-debug.apk

  4. Check the APK size in bytes:
       ls -la android/app/build/outputs/apk/debug/app-debug.apk

     The file size must be under 100MB (104,857,600 bytes). The research estimate is ~85-95MB after Filament removal for a debug build; release builds are typically smaller due to additional compression.

  5. Optionally verify the lib/ layer no longer contains Filament .so files by unzipping the APK and listing lib/:
       unzip -l android/app/build/outputs/apk/debug/app-debug.apk | grep "lib/.*filament"
     Expected: zero matches.
  </action>
